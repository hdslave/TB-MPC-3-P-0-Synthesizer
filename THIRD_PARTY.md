# Screen artwork, type and interfaces

The SP-16 panel uses the MIT-licensed [sixteen.screen extension header published with Anvil](https://github.com/hdslave/hdslave-Anvil-Synth/blob/main/src/sixteen_screen.h).

| Material | Origin and use |
|---|---|
| Departure Mono | Copyright 2022–2024 Helena Zhang. SIL Open Font License 1.1. The instrument uses six-pixel body advances, compact capitals and note names. [Source font](assets/fonts/DepartureMono-Regular.otf) · [Licence](licenses/OFL-departure-mono.txt) |
| Barlow SemiBold | Copyright 2017 The Barlow Project Authors. SIL Open Font License 1.1. Both MPC themes use antialiased glyphs for its labels, note names and readouts. The SP-16 panel uses antialiased glyphs at three sizes. [Font](assets/fonts/Barlow-SemiBold.ttf) · [Licence](licenses/OFL-barlow.txt) |
| Slink wordmark | Original lettering generated for this instrument with OpenAI’s image generator. The panel pairs it with the original Press Plate face. [Artwork](assets/art/slink.png) · [Panel and animation baker](tools/bake_sp16_panel.py) |
| Thorn Crown | Original chrome thorn sculpture and motion study for Slink. The desktop editor renders the shared thorn camera and step-counter artwork at four times the panel dimensions and matches the turning smiley to the shared 33 poses using the [original chrome artwork](mac-clap/tools/smiley/chrome-master.png) and [desktop smiley baker](mac-clap/tools/bake_smiley.py). Its panorama extends the original chrome whips and forked lightning with hand-drawn curves. [Shared artwork baker](tools/sp16_thorn/bake_native.py) · [Desktop header baker](mac-clap/tools/bake_header.py) · [Desktop whip composition](mac-clap/tools/footer-art/whip-panorama.js) · [Archived panel artwork and credits](mac-clap/tools/footer-art/) |
| SP-16 score lettering | Razor Choir is original Slink artwork for chrome pitch letters and cut numerals. The row legends and buttons use the panel’s swept lettering. [Pitch artwork](tools/sp16_thorn/razor-choir.js) · [Vector outlines](tools/sp16_thorn/lettering.js) |
| stb_image 2.30 | The desktop editor uses Sean Barrett’s stb_image to decode JPEG and PNG header artwork and expand zlib-compressed footer frames. MIT license. [Source and license text](mac-clap/third_party/stb/stb_image.h) |
| Barlow Condensed Bold Italic | Copyright 2017 The Barlow Project Authors. SIL Open Font License 1.1. Used for the seed digits and live value readouts. [Font](assets/fonts/BarlowCondensed-BoldItalic.ttf) · [Licence](licenses/OFL-barlow-condensed.txt) |

The score, articulation marks, filter plots, pickup indicators, controls and layout are drawn specifically for this instrument. The plug-in embeds native bitmaps compiled from C++ headers. The font binaries and exploration PNGs stay in the source tree. [Asset generator](tools/ui_preview/assets.py)
